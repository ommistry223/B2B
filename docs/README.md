# Documentation Index

This folder contains project documentation grouped by purpose.

## Folders

- deployment/: Production and hosting deployment guides
- setup/: Local and cloud setup instructions
- fixes/: Troubleshooting and targeted fix documents
- animations/: 3D and UI animation documentation
- summaries/: Completion and update summaries
- reference/: Quick references and checklists

## Notes

- Runtime code paths are unchanged (frontend stays in root src/, backend in backend/).
- Use root script `npm run dev:all` to start both frontend and backend.
